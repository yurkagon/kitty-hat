# Agent workflow

- Impeccable is disabled. Do not load or run it unless the user explicitly re-enables it.
- Do not automatically run documenter or design-review agents. Use subagents only when explicitly requested by the user.
- Do not automatically update PRODUCT.md, DESIGN.md or .impeccable/design.json for routine changes.
- Prefer small, direct changes with Ponytail. Keep image generation available when requested.
- Do not run tests when adding avatar profiles.
